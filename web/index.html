Lean in the browser

Lean 4 programs and the Lean compiler itself, transpiled to JavaScript by lean2js and running in this page.

Calculator

A compiled Lean program (a big-number calculator reading stdin). The small, fast one: the program is transpiled ahead of time and only the runtime runs in the page.
needs web/build.sh calc

Elaborator

The Lean frontend (parser, elaborator, compiler, kernel) runs in the page: type Lean source, press Elaborate and get #eval results, #check output and errors.
needs web/build.sh selfhost (170 MB of JavaScript + 160 MB of library files; first load takes about 40 s)

Script + data + console

A Lean script that reads data.json (statistics over a list of numbers), a JSON pane, and a console that evaluates what you type — main, terms, defs, any IO action.
needs web/build.sh selfhost

Infoview

An editor with the proof goals, expected type and messages at the cursor (like the VS Code infoview), also for a proof you are still writing (prefix mode).
needs web/build.sh selfhost

lsp.html — language server (planned)

The same with a language-server protocol layer and a live infoview; waiting for a design decision (docs/tickets/demo-002-lsp-infoview-in-demo.md).

Serve this directory with node web/serve.mjs 8000 (or python3 -m http.server -d web 8000) and open http://localhost:8000/. Headless-browser tests: web/test-browser.sh.
